# AgentVault 0.1.0-alpha.8

统一工作台新增 Qoder CLI 主会话只读接入：自动给出默认配置目录（支持 `QODER_CONFIG_DIR`）、自定义来源、可取消读取、文件失败报告、列表筛选、正文搜索和命中预览。复用现有扫描与 Claude 消息信封解析模块，并采用带 MIT 许可的 kage 格式夹具。Qoder 的删除、编辑、恢复、原生续聊和 IDE 数据不在本版范围。

长会话预览新增最早／最新顺序切换和快捷定位。末尾和远处搜索命中按 200 条事件窗口读取；消息列表、时间线刻度和展开的提问列表复用 TanStack 虚拟渲染，长过程组限制单段数量。搜索过滤下不自动连读剩余会话，避免少量命中引发无意的全量加载。

验证结果和边界见 [统一工作台](../unified-session-workbench.md)。JSONL 底层仍为顺序读取，首次时间线仍扫描全文件；显式加载全部仍需相应内存。本地夹具与 WebUI 验证不替代原生 Tauri 安装运行验收。版本标签仅触发 draft 制品，不正式发布。
