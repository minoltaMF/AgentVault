# AgentVault 0.1.0-alpha.25

Codex / Claude 用量缓存支持跨启动复用，减少应用重启后首次打开用量窗口的重复解析。

- 在现有配置目录旁新增可丢弃的 `usage-cache-v1.json`，不迁移目录、不更改 SQLite schema、配置文件或原生会话。WebUI 使用当前 settings 文件所在目录，保持 portable 和自定义配置隔离。
- 仅保存来源键、文件指纹、模型用量和统计提示，不保存对话正文、费用单价或会话标题。缓存仍有容量限制和 LRU 淘汰。
- 首次分析惰性加载，任务结束后批量保存，复用现有原子文件写入与冲突检查。损坏、不兼容或不可用缓存降级为重新解析/内存缓存，并在用量窗口提示；不以旧结果掩盖来源读取错误。
- 每次命中仍执行来源路径、打开和最终指纹校验。强制重新分析继续绕过缓存，追加或变更文件完整重新解析。元数据指纹不是内容哈希，保留全部元数据的内容修改仍可能无法识别。

## 验证

- `cargo test --manifest-path src-tauri/Cargo.toml --no-default-features`：606 项库测试、6 项 CLI 测试通过；其中 Windows 用量测试 28 项，Unix 另有软链接拒绝测试由 CI 执行。覆盖重载命中、变化失效、强制刷新、格式/解析版本/校验和拒绝、64 MiB 文件上限、10,000 条边界、并发创建冲突和不可用目录降级。
- `npm run test:frontend`：105 项通过；`npm run test:safety`：12/12；`npm run test:release`：24/24。前端构建、CLI 调试构建、格式检查、diff 检查及 alpha.25 发布元数据检查通过。前端仍有既有大 chunk 提示。
- 本地 WebUI 使用三条合成会话完成首次分析后，停止并重启 CLI，首次打开全部命中磁盘缓存。随后仅损坏临时缓存文件并再次重启，界面显示降级提示、三条会话全部重新解析，统计保持一致；控制台无错误或警告。浏览器在服务重启后曾显示空白加载页，重新加载后正常；未将此测试视为桌面安装验收。

## 独立进程重启基准

2026-10-11，Windows ARM 虚拟机运行 GNU x64 Rust 调试构建。本地 WebUI API 使用 Codex、Claude 各 60 个文件，每文件 1,000 条用量记录。每轮重启均停止旧进程并启动新进程；下表任务耗时包括首次缓存读取和任务结束保存，不包括启动服务及 UI 渲染。

| 场景 | 后端耗时 | 复用 / 成功解析 / 失败 |
| --- | --- | --- |
| 首次读取 | 5,728 ms | 0 / 120 / 0 |
| 三次独立重启后的首次读取 | 116 / 108 / 107 ms | 120 / 0 / 0 |
| 重启前追加一个 Claude 文件 | 137 ms | 119 / 1 / 0 |
| 强制重新解析 | 7,250 ms | 0 / 120 / 0 |
| 损坏缓存后重启 | 7,951 ms | 0 / 120 / 0，缓存降级提示 |

重启读取中位数 108 ms，API 墙钟中位数 132 ms；缓存快照 68,430 字节。逐项断言重启结果与冷读相等、追加后统计更新、强制解析一致、缓存损坏不改变统计且保留损坏文件。非故障注入阶段逐文件 SHA-256 复核，确认来源未被分析修改。样本仅三次，不代表尾延迟、发布构建或其他平台性能。
