# AgentVault 0.1.0-alpha.37

正文搜索命中导航：在正文筛选输入框旁显示当前命中 / 命中消息总数，提供上一处、下一处及 Enter / Shift+Enter。按当前显示顺序导航，首尾循环，并给当前消息增加持久边框高亮；输入法组合输入不触发快捷键。每条消息计一次，不统计同一消息内部重复词语的次数。

复用现有筛选、事件身份和虚拟列表定位，不新增后端扫描或索引协议。默认只搜索已加载范围，明确标注范围；用户选择「加载全部」后扩展计数并保留仍存在的当前命中。读取失败保留可导航的部分结果并注明读取中断。空结果和单结果禁用无意义的翻页；快速更换或清除关键词取消旧定位；工作台搜索指定的命中优先，搜索期间不覆盖普通阅读位置。

验证：前端测试 163/163、前端构建、安全矩阵 12/12、Rust 格式检查、发布元数据与 diff 检查通过。新增回归覆盖不连续原始索引、倒序、首尾循环、显式搜索目标、扩展结果保留选择，以及不完整或失败读取的范围说明。

真实 WebUI 使用 `http://127.0.0.1:43279` 独立合成 Claude 夹具验证 1,200 条消息：200 条窗口导航、上一处绕回第 200 条、Enter/Shift+Enter、零命中及单命中禁用、加载全部扩展至 1,200 条且保留第 200 条选择、跨原分页边界到第 201 条、倒序定位、文件失效后的部分结果导航以及恢复后重试。桌面及 390×844 窄窗口显示正常，控制台无相关 warning/error。Browser plugin not available，使用 CUA Playwright。未修改真实用户会话；未逐一验收十四个来源的特殊正文格式。

只创建 draft；跨平台制品以 CI 的完整清单及下载 SHA-256 校验为准。签名、公证及目标设备安装运行需另行验收。
