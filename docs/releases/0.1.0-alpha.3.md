# AgentVault 0.1.0-alpha.3 internal alpha

版本候选日期：2026-09-13。由新版本标签触发四平台 CI，制品保留为 draft。

## 功能与体验

- Codex 删除增加运行态保护；无法确认原生写入者停止时拒绝操作。
- 删除前创建可验证快照，快照失败则拒绝删除；删除前再次检查源文件指纹，沿用补偿事务。
- 新增删除快照管理界面：查看文件、完整校验、隔离恢复和恢复记录。恢复到新目录，完成后重新校验文件和 SQLite，不覆盖原生 Session。
- 新增 Codex / Claude 统一只读会话工作台，支持来源读取、过滤、搜索、分页与预览。
- 来源扫描支持取消、真实文件进度、文件级失败报告和重试；单文件失败可保留其余结果，取消或来源失败保留先前列表。
- 固定开发后提交、推送、注释标签与 CI draft 交付流程，所有版本默认保持 draft。

## 验证与边界

本轮功能验证已完成：前端 77 项测试、无桌面默认特性的 Rust 库 525 项测试、前端构建、Rust 格式检查，以及临时夹具下的 WebUI 操作。扫描验证包含约 21.6 MB JSONL、坏文件、取消、重试与窄屏；快照验证包含隔离恢复、损坏拒绝和恢复后校验。

本轮发布元数据检查与安全矩阵 11/11 已通过。版本交付还需通过同一提交的 CI / Release；GitHub 上的最终任务状态是制品构建依据。Windows 本地 GNU 工具链验证不能替代 macOS、Linux 或 Windows 原生桌面验收。

不迁移应用数据、配置路径或数据库 schema，不更改兼容包名、binary 名和 bundle identifier，不修改真实用户 Session 来测试。快照恢复不保证原生应用直接续接；扫描仍为进程内任务，关闭应用后不续扫。隔离恢复与 Vault 后续通用恢复能力保持独立。

Alpha 制品尚未签名或公证，只用于受控测试。应用内更新源默认关闭，GitHub draft 仅对有仓库访问权限的用户可见。
