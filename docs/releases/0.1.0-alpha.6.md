# AgentVault 0.1.0-alpha.6 internal alpha

统一工作台现在会在当前应用会话内保留成功扫描结果、筛选、页码与滚动位置。切换其他页面后返回无需重新扫描；刷新失败或取消仍保留上次成功结果和扫描时间。

缓存按 Provider 与当前来源隔离，来源变化后失效，迟到响应不覆盖新来源。离页仍请求取消正在进行的扫描。不新增磁盘缓存、自动扫描、Registry 或 schema；重新加载页面、关闭应用或新建窗口后需要重新读取。缓存是浏览结果，不是备份，也不保证源文件仍可用。

验证：前端 80 项测试、构建以及实际页面的固定接口夹具交互通过。覆盖导航返回、筛选、翻页、滚动恢复、刷新失败、取消、离页取消、延迟响应和来源切换；检查桌面与 390 px 窄窗口。后端未修改，原生桌面窗口和目标平台运行验收仍独立于 CI 构建。
