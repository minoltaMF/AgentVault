# AgentVault 0.1.0-alpha.11

统一工作台新增 Qwen Code、Cline CLI/Desktop、GitHub Copilot CLI 与 Antigravity 四个只读来源，共十四个来源。新增来源支持目录配置、单独读取与同时刷新、可取消扫描、文件级失败报告、筛选、正文搜索、命中定位与预览返回状态保留，不提供编辑、删除、恢复或原生续聊。

- Qwen Code：读取 chats/archive JSONL，按父链选择当前分支并聚合同 UUID 片段；身份不一致、缺失父节点、循环和未完整写入的尾行明确失败。
- Cline CLI/Desktop：读取 version 1 manifest/messages 成对文件，核对会话身份，不跟随 manifest 中的任意路径；不包含 VS Code 扩展历史。
- GitHub Copilot CLI：读取 session.start version 1 的当前与旧文件布局，正文与工具、子代理、临时和自动继续元数据分离；这是持久化历史投影，不重建压缩后的模型上下文，不包含 VS Code Copilot Chat。
- Antigravity：识别三类 app_data_dir 下的 transcript 和 brain Markdown；Markdown 每文件单独标为「产物·非完整对话」。目录依据官方文档，事件字段以锁定开源夹具为基线，不承诺所有官方历史版本兼容。

Qwen/Copilot 单会话读取上限 128 MiB，Cline 成对文件合计上限 50 MiB，Antigravity 每文件上限 50 MiB。附件与文内本地路径不解引用；预览可能先完整解析单会话再分页，不代表已实现随机访问或大规模性能验收。复用开源读取规则和最小测试夹具，不引入上游运行环境。来源与许可证见 [第三方声明](../../THIRD_PARTY_NOTICES.md)，具体目录和边界见 [统一工作台](../unified-session-workbench.md)。

QoderWork 已完成[格式核实](../qoderwork-format-verification-2026-09.md)，但尚无已验证的持久化 schema 或脱敏样本，本版未新增其来源入口。

本地已验证：前端 97/97，Rust lib 562/562。新增四来源联动回归覆盖扫描、坏文件隔离、正文搜索、命中预览和源文件不变。前端构建、CLI 构建、格式检查、12/12 安全矩阵及版本一致性检查均通过。真实 Rust WebUI 配合合成/开源夹具，在 1280×820 和 390×844 下验证四来源读取、正文搜索、命中预览、只读菜单、返回筛选及搜索状态、设置目录和源文件哈希不变，浏览器无 console/page error；未使用真实用户会话。标签 CI/draft 制品须以 GitHub 最终结果为准。版本标签仅触发 draft 制品，不正式发布；本地测试不表示原生安装运行、签名或公证通过。
