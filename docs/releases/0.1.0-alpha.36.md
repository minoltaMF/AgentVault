# AgentVault 0.1.0-alpha.36

包含 alpha.35 的正文阅读位置记忆，功能和界面验收详见 `docs/releases/0.1.0-alpha.35.md`。

alpha.35 两套 CI 全部通过、四平台代码均编译成功，但 macOS Intel CLI 上传前读取 GitHub API 时发生 `UND_ERR_CONNECT_TIMEOUT`，导致该附件未上传，完整性门禁正确拒绝通过。保留旧标签、提交与不完整草稿，不删除或覆盖资产。

本版针对该实际故障，为 GitHub GET 请求增加最多三次尝试，间隔 1/2 秒，仅覆盖明确的瞬时连接错误、超时及 HTTP 502/503/504。创建及上传等写请求不自动重发；已有唯一 draft、标签指向、同名附件摘要检查和上传超时后的查询恢复规则保持不变。权限、格式、摘要等永久错误不重试。

验证：发布脚本回归覆盖重试后成功、重试耗尽、写请求不重发和永久错误不重试；26 项发布测试、160 项前端测试、前端构建、安全矩阵 12/12、格式和元数据检查均通过。四平台完整性以本版 CI 的最终 14 件下载 SHA-256 校验为准。只创建 draft，正式发布、签名公证与目标机器安装运行不在此次验收范围。
