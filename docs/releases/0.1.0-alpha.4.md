# AgentVault 0.1.0-alpha.4 internal alpha

版本候选日期：2026-09-13。这是 alpha.3 的最小跨平台编译修复，功能范围继续参见 [alpha.3 发布说明](0.1.0-alpha.3.md)。

macOS 的 `statfs.f_flags` 为 `u32`，而 `libc::MNT_LOCAL` 常量为 `i32`。运行态保护中的本地文件系统检测现显式转换标志类型，保留原有拒绝非本机来源的行为。alpha.3 的 macOS CI 在编译阶段发现此问题，原标签保留，不改写历史。

不新增功能，不调整数据或兼容性标识。此修复只涉及 macOS 条件编译路径；Windows 本地检查不能证明 macOS 构建成功，最终以本标签的四平台 Release 和同一提交的 CI 为准。制品保持 draft、未签名和未公证，正式发布另行授权。

交付流程见 [发布约定](../release-workflow.md)，数据保护边界见 [删除快照](../codex-delete-snapshots.md)。
