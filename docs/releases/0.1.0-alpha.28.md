# AgentVault 0.1.0-alpha.28

Codex / Claude 用量分析增加最近 7 / 30 天与上一周期的对比。

- 使用相邻、不重叠、等长的 UTC 日期区间。本期包含今天已记录用量，明确提示当天可能尚未结束，不外推全天。
- 对比已记录 Token、已知费用、绝对差额与变化百分比。Token 不重复计算推理及缓存子集；两期使用相同的当前录入单价，不等于历史账单。
- 对比范围复用当前工作台筛选，独立于下方日期筛选；可直接查看本期或上期明细。切换周期只汇总已加载日桶，不新增文件读取或缓存格式。
- 缺少单价时仅比较已知费用差额，不显示费用涨跌百分比。无记录不视为零；上期为零但本期非零不计算百分比。分析未完成、读取失败、解析警告、无日期用量或计算溢出时拒绝显示误导性涨跌。
