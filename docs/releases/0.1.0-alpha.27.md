# AgentVault 0.1.0-alpha.27

Codex / Claude 用量分析增加日期筛选、按日趋势与高消耗日期定位。

- 支持全部、近 7 天、近 30 天和自定义起止日期。按原生用量事件的 UTC 日期归属，包含边界；日期变化即时重算已加载结果，不重新扫描文件。汇总及会话、模型、项目明细同步筛选。
- 保留 Codex 跨日累计差分与 Claude 响应去重；同值重放保持原归属日，确认的修订整体归修订事件日。缺失/非法时间单列，仅进入全部日期总量，不能用会话创建或修改时间补齐。首条累计值及原生数据不完整等既有歧义继续提示。
- 复用现有 EChart 展示 Token / 已知费用趋势；Token 不重复计算推理和缓存子集。仅绘制有记录日期，不把缺日解释为零。图表最多展示最近 90 个有记录日期，表格保留全部、每页 10 行，支持按日期、Token、已知费用排序及单日下钻。
- 费用使用本机当前录入单价，缺单价/解析提示显示已知部分，溢出拒绝计算，不等于实际账单。窄屏表格支持横向滚动，日期和操作按宽度换行。
- 日桶进入既有用量缓存，解析版本升至 2。旧缓存保留并降级内存复用，重新解析来源；点击「安全重建缓存」完成备份、读回验证和 CAS 后恢复新版本的跨启动缓存。不改变文件名、应用目录、数据库 schema 或模型单价，不写原生会话。
