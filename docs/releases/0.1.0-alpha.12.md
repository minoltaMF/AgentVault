# AgentVault 0.1.0-alpha.12

统一工作台优化来源管理：未使用来源默认折叠，已使用来源以紧凑行展示，减少十四张来源卡片占用的空间。

- 展开未使用来源后，优先显示已设置目录的来源；读取后进入已使用区域。
- 「已配置」表示已设置目录，不表示工具已经安装或来源可读取。应用预填的默认路径仍需通过读取确认。
- 目录、上次扫描时间及扫描详情按需展开；读取失败、状态待确认或文件级部分失败自动展开详情，保留失败报告、停止及重试入口。
- 页面返回保留已使用状态、未使用区域与详情展开状态。缓存仅在当前应用生命周期内有效；目录变化重置相关视图状态并沿用来源缓存隔离，关闭应用后不持久保存。
- 折叠不取消扫描，不移除列表或正文搜索中的结果。顶部刷新覆盖全部十四个已设置目录的来源，补齐此前漏掉的八个来源。
- 增加「配置来源」入口，直接打开现有设置面板。

本版不增加新来源或原生会话写入能力，不更改原生文件、配置路径或数据库 schema。使用方式见 [统一工作台](../unified-session-workbench.md)。

已验证：前端测试 98/98、生产构建、Rust 格式检查及版本一致性检查通过。实际 Rust WebUI（沿用 alpha.11 后端可执行文件，本轮仅前端逻辑变更）在 1280×820 与 390×844 下验证初始折叠、已用来源紧凑显示、键盘焦点、详情与分组返回状态、预览筛选保留、部分失败报告、目录变更重置、全部十四来源刷新及窄屏无横向溢出；主流程无 console/page error。额外通过延迟真实请求验证折叠不取消扫描、显式停止只发一次请求。使用临时夹具和测试配置，未读取真实用户会话。

本机安全矩阵受既有 Rust 依赖缓存缺失源码文件（autocfg/unicode-ident）阻断，未将其计为通过；完整 Rust 与安全矩阵由标签 CI 验证。CI/draft 最终状态以 GitHub 为准。版本标签仅触发 draft 制品，不正式发布；本地检查不表示原生安装运行、签名或公证通过。
