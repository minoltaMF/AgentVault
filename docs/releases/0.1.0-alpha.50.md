# AgentVault 0.1.0-alpha.50

长会话连续搜索性能优化：共享当前关键词、消息筛选下的事件匹配结果，减少逐页读取后对旧消息的重复筛选，并保持取消与命中定位行为。

## 范围与测量

- 复用已有搜索文本 WeakMap，新增仅驻留当前预览的匹配缓存；换词、筛选和时间线变化失效，重读的新事件对象重新计算。
- 合并累计筛选遍历，复用可见事件索引；未展开上下文时复用结果列表，无需间隔时不再扫描间隔。
- 五轮交替合成微基准中，30,000 条消息累计筛选 p50 从 2,087.69 降至 207.81 ms，最后一页从 25.11 降至 1.91 ms。取消定时器派发 p50 从 26.75 降至 6.17 ms，取消后新增读取均为 0。
- 这些数值仅为 Node CPU 微基准，不含后端、React 渲染或浏览器点击延迟。取消回调至循环退出阶段没有同步加速，样本较少且存在宿主调度波动。完整方法、原始摘要及后端分页基线见 [性能记录](../preview-search-performance.md)。
- 不新增依赖、后端缓存、schema 或原生会话写入；后端重复前缀解析仍是后续优化边界。

## 验证与环境

- 前端测试 226/226，包含 6 项新增缓存失效、重读、前后补页和旧实现等价回归；前端构建通过，保留既有大分块提示。
- 实际 WebUI 使用合成 900/30,000 条会话，验证跨页命中即停、完整无命中、上下文/间隔展开、改词及筛选变化、取消后的范围稳定与再次继续。桌面及 390×844 窄窗口验收通过，控制台未见错误。
- 宿主临时 npm、Rust/MinGW 组件及 Cargo 源缓存不完整，已在隔离目录恢复同版本工具。恢复后 GNU 默认链接产物在测试启动前崩溃，显式使用同版配套 LLVM 链接器后原失败用例通过；未修改产品依赖、测试断言或全局工具链。
