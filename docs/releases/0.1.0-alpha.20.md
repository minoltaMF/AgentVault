# AgentVault 0.1.0-alpha.20

统一工作台新增「用量与成本」，一期覆盖 Codex、Claude。分析当前筛选范围的全部会话，不限当前页；支持按会话、模型和项目查看。

- 归一化未缓存输入、输出、缓存读取、缓存写入及一小时缓存写入；推理 Token 是输出的子集，不重复计价。按响应身份处理修订和重放，支持 Codex 累计计数与压缩场景。
- 用户按来源和模型录入五类 USD / 百万 Token 单价，保存在当前客户端 localStorage；刷新后保留。留空表示未知，显式 0 表示免费，不内置或自动获取模型价格。
- 后台分析提供真实文件进度、取消和文件级失败报告；部分失败保留成功结果，缺少用量、价格及歧义记录明确提示，估算不等于实际账单。不同会话文件间不推断全局账单去重。
- 原生会话只读，读取前后检查路径边界并最终复核文件指纹；读取中变化、非法路径、超限文件和损坏记录拒绝计入。仅使用合成夹具验证，未修改真实用户会话。
- 每次分析重新读取文件，没有新增持久用量缓存或数据库 schema。单次最多 10,000 个会话，同时最多两个任务；文件上限 256 MiB、单行 8 MiB、250,000 行。大量会话的持久增量分析留待后续。
- 复用 Magpie 锁定版本的响应身份、累计差值、修订去重及缓存 TTL 规则与合成回归夹具，来源和 MIT 许可证见 THIRD_PARTY_NOTICES.md。不引入 Go 运行时、网关、认证或模型调用。未完整移植复杂分页恢复和跨计数域推断；歧义通过读取提示展示，不能据此认定精确账单。

验证：Rust 599/599（含新增用量测试 21 项）、前端 105/105、安全矩阵 12/12 通过；前端构建、debug CLI 构建及 Rust 格式检查通过。实际 WebUI 使用临时合成来源验证重复消息不重复计数、五类单价、未知与零的区分、刷新后单价保留、跨来源汇总及文件失败隔离；API 验证重新读取的一致性和取消。构建存在原有大 chunk 提示。

此版本仅生成 draft；CI、四平台构建和制品上传结果待验证。构建成功不代表正式发布、签名、公证或各平台安装运行验收。
