# AgentVault 0.1.0-alpha.29

Codex / Claude 用量分析增加 CSV 导出。

- 导出当前日期范围汇总、全部每日趋势和当前所选 7/30 天周期对比；沿用界面 UTC 日期与当前本机单价，周期独立于日期筛选，不受分页或图表日期上限影响。
- CSV 使用 UTF-8 BOM、CRLF 和固定列，按 `record_type` 区分元信息、汇总、每日、两期、差额及质量说明。保留分析状态、失败数量、缓存提示、无日期用量、解析警告、缺记录与未知费用。空数值不冒充零，已知费用部分与完整费用明确区分；不导出正文、原始路径或原始错误内容。
- 复用已有汇总、去重和周期逻辑；按日一次分桶，避免每个日期重新扫描全量数据。只在点击导出时生成文件；分析中和无效日期范围禁用导出，取消或失败后允许导出标注为部分结果的数据。
- 浏览器请求本机下载，桌面版选择新的绝对 `.csv` 路径，复用原子 create-if-absent 写入。拒绝已有文件、路径跳转、符号链接/junction 目录及超过 32 MiB 的报告；取消保存不写文件。文本转义并防止表格公式注入。
- 修复窗口跨 UTC 日重新打开时周期截止日期可能陈旧的问题，CSV 与界面共享同一日期基准。
