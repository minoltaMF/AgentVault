# AgentVault 0.1.0-alpha.40

单条消息内多处命中导航：保留原有消息级上条/下条与 Enter / Shift+Enter，新增本条第几处/共几处及上处/下处，支持首尾循环，并以橙色描边区分当前关键词和其他黄色高亮。导航复用虚拟列表与嵌入历史的内外层滚动定位。

计数以当前消息已展开正文中的高亮为准，工具等折叠标题中的重复摘要不重复计数。Markdown 跨粗体等行内格式拆成多个 mark 的同一次匹配共享 ID，只计一次；不同渲染片段使用独立 ID。换消息、换词及清除搜索重置本条选择；收起/展开更新计数并约束下标。当前消息被虚拟列表卸载后保留计数，继续导航时重新定位并加载目标行。不引入全文扫描、后端协议、持久配置或原生会话写入。

验证：前端 180 项测试及构建、安全矩阵 12/12、发布流程回归 26/26、Rust 格式检查、版本元数据与 diff 检查通过。新增回归覆盖跨格式分组、不同段落/组件 ID、重渲染分组稳定、内部首尾循环、零/单命中与数量缩减。真实 WebUI 使用 http://127.0.0.1:43279 的独立合成 Claude 夹具，验证一条消息 8 处匹配、首尾循环、代码/表格定位、换消息重置、清除重搜、零命中禁用、嵌入历史收起/展开计数变化，以及 1,200 条消息夹具中每条 30 处匹配、当前行卸载后恢复导航。1280×720 与 390×844 页面检查通过，控制台无相关 warning/error。Browser plugin not available，使用 CUA Playwright。

本条计数不代表原始 JSON 或整个会话的关键词总数，不改变消息级搜索匹配规则；尚未逐一验收十四个来源的特殊正文格式。Release 保持 draft，四平台制品以 CI 完整清单与下载 SHA-256 校验为准；签名、公证和目标设备安装运行未验收。
