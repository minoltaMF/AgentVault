# AgentVault 0.1.0-alpha.49

连续查找到下一处命中与取消：用户可从已加载范围向前或向后连续读取相邻页，发现新命中即停止，并随时取消。

## 行为与边界

- 「连续查找」提供按时间顺序向前、向后的入口，每页最多 200 条原始事件，串行读取；不因整页被筛选而提前停止。
- 按当前关键词和消息筛选寻找新增范围内最近的命中；发现命中、到达边界或读取失败即停止，显示已读取页数和事件数。
- 取消立即停止后续调度，保留已经接收的内容。已发出的后端读取仍需结束，但取消后返回的页面不加入结果；再次启动从已接受的边界继续。
- 改词、改筛选、关闭或切换会话使旧任务失效。时间线跳转先取消查找，等待在途读取结束后接管定位，避免旧请求覆盖新位置。
- 复用现有安全分页、消息筛选和虚拟列表，不新增依赖、后端协议、schema 或原生会话写入。结果仍只针对当前筛选及已读取内容；原文件变化后需重新读取。
