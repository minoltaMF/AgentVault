# AgentVault 0.1.0-alpha.24

用量分析增加按文件增量缓存，改善 Codex / Claude 大会话重复打开的等待体验。

- 同一进程内复用未变化文件的解析结果；追加、截断或指纹变化的文件完整重新解析，保持原有响应去重与累计计数规则，不将追加行直接累加为新账单。
- 缓存键隔离来源类型、根目录及文件路径，保留当前会话标题和项目元数据。命中仍检查路径、打开文件并对句柄和路径做最终指纹复核；读取失败不以旧结果顶替。
- 最多 10,000 项、约 16 MiB 权重预算的 LRU 缓存，只保存用量和提示，不保存正文、不落盘；重启后清空。不新增数据库 schema 或修改原生会话。
- 界面显示缓存复用、成功重解析文件数和耗时，提供「强制重新分析」。关闭再打开恢复常规缓存模式，保留分组和分页；轮询仅耗时变化时复用前端结果引用，减少重复汇总计算。
- 指纹基于文件元数据，不是内容哈希。Unix 增加 ctime；Windows 沿用创建时间、修改时间和大小。主动保留全部这些元数据的修改可能无法识别，可使用强制重新分析。现有路径检查不等于原子打开，仍不声称消除所有 TOCTOU 竞态。
