# AgentVault 0.1.0-alpha.39

搜索命中自动展开折叠内容：推理、工具调用/返回、事件详情和嵌入历史的内部内容匹配当前搜索词时自动展开，复用正文高亮与命中消息导航。嵌入历史有独立滚动区域时，先将内部关键词滚入可见区域，再对齐外层正文列表。

普通阅读的手动展开状态与搜索临时状态分离。搜索中允许手动收起，当前词下保持该选择；换词或清除搜索即重置临时选择，恢复普通阅读状态。普通状态在当前预览中按原始事件索引保留，不因筛选或虚拟列表卸载丢失；关闭/换会话后重置，不新增持久存储。尊重「仅看对话消息」筛选，不强制显示原本被排除的工具或推理事件。

本地验证：前端 176 项测试及构建、安全矩阵 12/12、发布流程回归 26/26、Rust 格式检查、发布元数据及 diff 检查通过。新增 6 项覆盖匹配展开、不匹配保持、搜索手动收起、换词/清除、原始状态恢复、事件隔离、重新挂载与重新搜索。真实 WebUI 使用 http://127.0.0.1:43279 独立合成 Claude 夹具，验证推理、工具参数/返回、100 行嵌入历史末尾的命中导航、搜索临时收起、清除恢复、筛选卸载后恢复与同词重搜。1280×720 和 390×844 均可看到历史末尾高亮，控制台无相关 warning/error。Browser plugin not available，使用 CUA Playwright。未修改真实用户 Session。

保持命中消息计数及已加载范围，不新增全文扫描、索引协议或原生写入。未逐一验收十四个来源的特殊事件格式。Release 保持 draft，四平台制品以 CI 完整清单及下载 SHA-256 核验为准；签名、公证和目标设备安装运行未验收。
