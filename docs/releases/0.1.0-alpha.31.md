# AgentVault 0.1.0-alpha.31

模型单价支持本机变更历史与恢复。批量编辑、配置导入和历史恢复都会保留操作前配置，可预览字段变化后恢复整份配置；恢复本身也可撤回。

历史最多保留最近 20 条且总计不超过 2 MiB，超限淘汰最旧记录。原有单价键和 version 1 格式不变，历史使用独立本机存储，不迁移已有数据。不包含会话正文，不追溯启用功能前的操作，不作为历史账单。

保存先写入历史日志，再更新单价；历史无法保存则拒绝修改，价格写入失败保留可判定日志。损坏或不一致数据拒绝覆盖。新版写入使用同一 Web Lock 串行化并检查原始值；旧版客户端及外部直接写入不受此锁约束，不宣称系统级原子事务。不支持 Web Locks 的环境保留查看及导出，拒绝保存与恢复。
