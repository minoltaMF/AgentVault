# AgentVault 0.1.0-alpha.34

正文预览区分空会话、筛选无匹配消息、文件失效及读取失败。读取失败显示持久提示、可展开错误详情和「重新读取正文」；失败后不再显示已到末尾，已加载内容明确标记为部分结果。

重试从最早位置重新读取，清除旧窗口并刷新时间线，避免失败偏移继续追加造成重复或混合。沿用请求代次保护，关闭或切换会话后的旧请求不更新当前界面；只读及返回用量排行行为保持。

公共正文读取接口沿用字符串错误传输，增加明确的失效/失败标识；按错误类型判断，不解析本地化错误文字。Codex、Claude 的完全不可解析非空文件不再被当作空会话；混合有效和损坏行仍沿用原有容错预览行为。其他来源沿用各自解析行为，共享错误提示与重试入口。

不修改原生会话、不迁移 schema、不升级项目依赖。只生成 draft；签名、公证和目标机器安装运行需要另行验收。

验证：`npm run test:frontend` 157/157、`npm run build`、`cargo test --locked --manifest-path src-tauri/Cargo.toml --no-default-features --lib preview_` 18/18、`npm run test:safety` 12/12、`cargo fmt --all -- --check`、发布元数据检查均通过。临时 Rust/C 编译工具链及 registry 残缺文件已在隔离目录修复，未升级项目依赖。

使用本轮编译的 WebUI 后端及独立合成夹具验证了 Claude 文件移走、恢复后重试、损坏 JSON、空文件、已读取 200 条后后续页失败、恢复并重新读取、Esc 返回，以及 390×844 窄窗口；Codex/Claude 的错误契约和恢复路径由 Rust 回归共同覆盖。界面无相关控制台 warning/error。Browser plugin not available，使用 CUA Playwright 验收。没有修改真实用户会话。
