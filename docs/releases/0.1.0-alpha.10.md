# AgentVault 0.1.0-alpha.10

统一工作台新增 DSH（DeepSeek Harness）、Hermes Agent、ZCode 只读来源，并纳入已有 OpenCode 解析能力。十个来源可同时刷新，支持自定义目录、可取消扫描、失败报告、筛选、正文搜索、命中定位和预览返回；来源目录变化隔离旧缓存与搜索结果。

DSH 读取 v3/v4 canonical JSONL 或 Zstd 连续压缩帧，选择最高格式代次；旧版、未知必要事件、损坏或截断数据明确报错，不回退旧日志。单会话解压正文上限为 128 MiB。其预览为历史事件投影，不承诺复现原生当前上下文或分支。Hermes 只读访问 state.db，ZCode 只读访问 cli/db/db.sqlite 并遵循原生消息顺序。新增来源不提供编辑、删除、恢复或续聊，工作台中的 OpenCode 隐藏写入操作；OpenCode 独立页面保持既有功能。

复用 agent-sessions、DeepSeek Harness 和 ZCode 的小模块规则与测试思路，不引入整套上游运行环境。路径、兼容边界与来源见 [统一工作台](../unified-session-workbench.md)、[接入基线](../agent-source-intake-2026-09.md) 和 [第三方声明](../../THIRD_PARTY_NOTICES.md)。预览分页不代表底层随机访问或大规模性能验收。

本地验证：前端 93/93、Rust lib 548/548、安全矩阵 12/12 与前端构建通过。四来源扫描、搜索和命中预览联动测试通过；最终 DSH 工具返回与工具元数据补充回归 3/3 通过；格式与发布元数据检查通过。Rust WebUI + Edge 实测四来源扫描、搜索、命中预览、返回保留条件、筛选与设置保存，1280×820 和 390×844 无横向溢出或应用错误，测试源文件 SHA-256 不变。CI 与制品状态以对应标签工作流最终结果为准，标签仅触发 draft 制品，不正式发布；未据此宣称原生安装运行、签名或公证通过。
