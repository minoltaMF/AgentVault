# AgentVault 0.1.0-alpha.38

正文搜索关键词高亮：复用现有正文筛选与命中消息导航，对显示正文中不区分大小写的字面匹配添加高亮，覆盖 Markdown 段落、粗体、链接文字、行内/围栏代码、列表、表格和展开的纯文本。搜索导航对齐消息中首个可见高亮词，减少长消息内的再次滚动。链接目标、代码原文和会话文件保持不变，不注入 HTML，不增加依赖。

工具等原始 JSON 在搜索期间展开为带高亮的格式化文本，清除搜索后恢复原有树形查看器。折叠内容仍需用户展开；仅属性、Markdown 标记或未展示元数据匹配时可能没有可见高亮，此时导航回退到消息起点。每条消息仍计一次，范围仍以已加载窗口为准，不引入全文扫描或词级导航。
