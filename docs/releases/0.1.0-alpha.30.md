# AgentVault 0.1.0-alpha.30

Codex / Claude 用量窗口增加集中模型单价管理。

- 默认集中列出实际用量缺少单价的模型，支持全部配置、来源/模型搜索和分页；空值为未知，0 为免费，无用量字段不会误报缺价。
- 多模型、多字段草稿跨筛选和分页保留，一次完整校验后保存；未编辑字段保持不变，保存失败保留草稿。关闭窗口前提示未保存修改，保存前检测其他窗口的配置变动，不把此检查宣称为跨窗口原子事务。
- JSON 导入严格校验后展示新增模型、字段覆盖与保留数量，显式应用合并；未提供字段和其他模型保持原值。导出仅包含已保存配置，不包含会话正文或路径。保留原有 version 1 配置和存储键，兼容未知模型空名称。
- 配置限制 1 MiB / 1000 模型；拒绝非法版本、负数、非有限单价、未知字段及模型键别名冲突，合并超限显示错误。浏览器使用本地文件与下载，桌面读取有界、导出原子创建新文件并拒绝覆盖、符号链接及 junction 目录。
