# AgentVault 0.1.0-alpha.21

修复四平台并发发布时，同一标签可能创建多个 draft、附件分散的问题。

- 新增独立 prepare 阶段，预先创建或复用唯一 draft，四个平台统一使用其 release ID。
- Tauri 只构建，所有桌面、CLI 和 portable 制品按 ID 上传；不按标签重新选择 Release，不覆盖已有不同内容附件。
- 同标签工作流串行运行；每次上传复核唯一 draft、标签和构建 commit，拒绝多个草稿、正式 Release 和错误指向。
- 新增最终门禁，要求四平台成功、14 件 alpha 制品完整且无额外/重名/未完成附件，并重新下载全部附件校验大小与 SHA-256。稳定版清单额外包含 MSI。
- 21 项模拟 API 与清单回归测试覆盖创建/复用、分页查重、拒绝写入、超时恢复、文件缺失和校验和错误。旧 alpha.20 草稿与原始附件保留。

本地发布回归 21/21、前端 105/105、安全矩阵 12/12 通过，前端构建、Rust 格式与版本检查通过。远程 CI / Release 及全附件下载校验结果待实际验证。此版本仅创建 draft；构建和下载校验不代表正式发布、签名、公证或安装运行验收。
