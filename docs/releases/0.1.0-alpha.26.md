# AgentVault 0.1.0-alpha.26

用量窗口增加缓存管理，支持查看大小、状态并安全重建 Codex / Claude 用量缓存。

- 显示磁盘缓存大小、内存条目数和估算占用；区分等待校验、可用、缺失、降级和未配置。状态依据最近一次分析/重建及当前路径元数据，不代表每次刷新都重新验证全部内容。
- 「安全重建缓存」先原样备份当前缓存并读回验证 SHA-256，再通过现有原子 CAS 替换为空快照，清空内存缓存并重新分析当前筛选范围。其他范围下次打开时重新生成；不修改原生会话、模型单价或现有数据库 schema。
- 分析运行中或取消尚未完成时拒绝重建；重建与新任务注册串行化。备份失败、并发内容变化、链接/非普通路径及超大文件均拒绝替换，保留已生成备份，界面显示失败和备份位置。
- 备份使用唯一文件名，不覆盖既有备份、不自动清理。最近备份位置只保留在本次进程状态中，备份文件随进程退出仍保留在缓存旁。
