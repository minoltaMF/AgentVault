# AgentVault 0.1.0-alpha.46

阅读与搜索记忆管理：正文工具栏增加“记忆”入口，可清除当前会话或全部阅读与搜索记录，关闭或重新开启自动记忆。关闭后停止保存和恢复，保留已有记录；清除后所有已打开的预览暂停保存，重新打开后按开关设置记忆。每次变更推进本机版本，旧视图和延迟任务不能回写；存储失败提示可能部分完成，不误报成功。不修改原始会话，不迁移既有记忆格式。

验证：前端测试 204/204、安全测试 12/12、发布流程测试 26/26 通过；前端构建、版本一致性检查及 Rust 格式检查通过。使用合成会话在实际 WebUI 验证关闭后不恢复、重新启用、当前会话清除后继续输入不回写，以及两个会话的全部清除；桌面与 390 像素窄窗口入口可用，控制台无错误。存储失败与损坏拒绝路径由单元测试覆盖；跨窗口通过版本失效机制保护，未单独做多窗口界面验收。保持 draft；目标设备安装、签名和公证未验收。
