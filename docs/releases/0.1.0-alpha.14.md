# AgentVault 0.1.0-alpha.14

统一工作台持久正文索引扩展到 Qoder CLI、WorkBuddy、Grok Build CLI、Pi，共六个来源。其他八个来源继续原有扫描。

- 复用既有 Registry 事务、查询规则、文件指纹、取消与文件级失败报告。
- Qoder / WorkBuddy 使用现有分类器，Grok / Pi 使用与预览一致的回退、分块和活动分支投影，避免索引废弃内容。
- Grok 配套 summary.json 参与失效判断与可见性校验。
- 重启后可载入四来源历史列表并直接打开命中；原生刷新空结果也会替换历史列表。
- 不新增依赖、schema 迁移或原生会话写入能力。

本地验证通过：前端 100/100、Rust lib 568/568、安全矩阵 12/12，前端与 CLI 构建、Rust 格式、版本一致性检查通过。索引回归覆盖冷建/复用、数据库重开、根目录隔离、变化后重建、坏尾行和取消保留旧事务、Grok 配套元数据与回退、Pi 活动分支及原始命中偏移。

Rust WebUI + Edge 使用既有开源/合成夹具，验证四来源读取、冷建 4 个索引、进程重启后加载并复用 4 个索引、四来源命中预览与返回，以及 1280×820 / 390×844 界面。源文件 SHA-256 不变，无浏览器应用错误。首次页面加载曾超时，重试与本地静态资源目录下的重启流程均通过；未使用真实用户会话，未进行本批四来源的大规模性能基准或原生安装包运行验收。

索引是本机派生缓存而非备份，变化文件仍完整解析，缓存列表为历史元数据；详细范围见[统一工作台](../unified-session-workbench.md)。版本标签仅生成 draft，不代表正式发布、签名公证或各平台安装运行验收。
