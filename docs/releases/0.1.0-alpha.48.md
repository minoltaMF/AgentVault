# AgentVault 0.1.0-alpha.48

正文搜索范围提示与继续查找：区分已加载范围和读取完成的整个会话，按当前消息筛选报告命中情况。用户可按需向前或向后读取相邻一页，不自动扫描整段会话；延续既有分页、安全读取及命中导航。

## 行为与边界

- 常驻显示原始事件范围、消息筛选及前后边界。开头、EOF、读取成功三个条件齐备后才报告整个会话的结果；整页返回需继续确认末尾。
- 每次最多读取 200 条相邻原始事件，整页被过滤也不自动连读；补页保留当前命中及本条关键词位置。
- 读取失败保留已有内容，明确提示结果不完整，并提供原方向重试。搜索期间不使用旧替换式分页或键盘隐式加载。
- 结果仅针对当前筛选与已读取内容；原文件新增或变化后需重新读取。复用现有安全读取，不新增原生文件写入、依赖或 schema。
