# AgentVault 0.1.0-alpha.35

正文阅读位置记忆：按来源与精确会话文件路径保存最近 100 个会话的阅读事件、排序方向及仅看消息模式，关闭重开或同一应用环境刷新后继续阅读。位置保存在本机 localStorage，不保存正文，不修改原生会话；备份/导入预览不记录位置。

恢复直接读取目标附近最多 200 个事件，核对事件序号、原始索引及内容变化摘要后定位。目标截短或改写时提示并回到开头；原有时间线仍单独读取。搜索命中优先且不覆盖普通阅读位置，读取失败不覆盖已有记录；保留从最早位置阅读入口。记录的是事件位置，不是长消息内部精确像素。浏览器不同端口/配置文件与桌面 WebView 的记录相互独立，清理站点数据会清除记录。摘要只用于变化检测，不是安全指纹。

验证：`npm run test:frontend` 160/160；`npm run build`、修正后的 TypeScript 检查与 Vite 构建、`npm run test:safety` 12/12、`cargo fmt --all -- --check`、发布元数据及 diff 检查通过。未改动 Rust 业务逻辑，安全矩阵使用既有隔离 Rust 工具链。

真实 WebUI `http://127.0.0.1:43279` 使用独立合成夹具，验证 1,200 条 Claude 对话：滚动后立即关闭重开、连续重开不漂移、刷新后恢复、倒序保留、文件截短回到开头、文件失效后关闭并恢复文件仍保留位置、搜索第 600 条优先于第 1196 条阅读记录且不覆盖记录、从最早位置阅读。桌面及 390×844 窄窗口提示与操作可用；无相关控制台 warning/error。Browser plugin not available，使用 CUA Playwright。没有修改真实用户会话。UI 验收以 Claude 为主，位置隔离和变化检测有来源无关单元测试；未逐一实测十四个来源的特殊事件格式。

仅创建 draft，正式发布、签名公证及目标设备安装验收不在本次范围。
