# AgentVault 0.1.0-alpha.33

排行关联会话新增「查看正文」，复用现有只读预览。可通过「返回用量排行」、Esc 或关闭按钮返回原关联列表，保留模型/项目分组、费用/Token 排序、日期范围、两级分页、滚动位置和未保存的单价草稿。返回不重新启动用量分析。

会话按来源和原生路径在当前分析范围内唯一匹配，不以同名标题或复用的 ID 猜测目标；无法匹配时显示提示。正文为完整会话，不按排行的日期或模型过滤。正文打开仍使用原有读取接口及保护；不增加原生写入或修改存储 schema。

验证：155 项前端测试通过，新增用例覆盖跨来源、同 ID 不同路径、缺失及歧义目标。生产构建通过。临时合成 Codex / Claude 浏览器验收覆盖正文、连续切换会话、三种返回方式、费用排序与日期保留、未保存单价草稿保留；实测返回前后 scrollTop 均为 1671，焦点恢复至原正文按钮。临时移走合成文件后可正常返回；390×844 窄窗口入口可见可用。没有修改真实会话。Browser plugin not available，使用 CUA Playwright 完成浏览器验收。

本版本仅生成 draft；原生安装运行、签名和公证不包含在浏览器验收中。完整平台结果以同提交 CI 和 Release 为准。
