# AgentVault 0.1.0-alpha.42

搜索上下文跨页加载：当前命中前后不足 3 条可见消息时，按需读取相邻一页（最多 200 条原始事件），再展开符合当前筛选的邻近消息；边界按钮显示「加载更早一页 / 加载更晚一页」。不循环扫描全会话，即使一页全部被过滤，也需再次点击继续读取。已有内容、命中消息身份和本条关键词序号保持不变。失败显示「重试上下文读取」，可重试同页，无需从头打开。

复用 previewRange 与现有 readWindow、虚拟列表和滚动定位，独立记录尾部读取结束状态，向前补页不再覆盖尾部边界。分页使用原始事件 offset 而非源行号；保留前页短读拒绝检查。同步 loading ref 防止重复拼页，会话代次与请求序号防止旧请求重设已改变的搜索、筛选或时间线定位。无依赖、后端协议、schema 或原生 Session 写入变更。

验证：前端 186 项测试及构建通过，新增回归覆盖不足 3 条时单页请求、首尾独立、无可见邻居、prepend 保留 EOF 和 replace/append 更新 EOF。真实 WebUI http://127.0.0.1:43279 使用 900 条合成 Claude 事件，初始读取 200 条，第一次后补只增至 400 条（整页推理被过滤），第二次才增至 600 条并展开 3 条；两次均保留第 8/8 处。另验证倒序尾窗向前补页、测试文件临时移走后保留正文与 8/8、恢复文件后原地重试，1280×720 与 390×844 布局及返回定位通过，控制台无相关 warning/error。Browser plugin not available，使用 CUA Playwright。异步失效路径经独立代码审阅修正，未以人工延迟响应逐项注入竞态。

安全矩阵 12/12、发布回归 26/26、Rust 格式、元数据和 diff 检查通过；四平台构建与 14 件制品下载 SHA-256 校验以 CI 为准。Release 保持 draft；未逐一验收十四个来源格式，签名、公证及目标设备安装运行未验收。
