# AgentVault 0.1.0-alpha.5 internal alpha

版本候选日期：2026-09-13。包含 [alpha.3 功能](0.1.0-alpha.3.md) 与 [alpha.4 macOS 编译修复](0.1.0-alpha.4.md)，修复 Windows 8.3 短路径下的删除快照匹配。

alpha.4 四平台 Release 构建成功，但完整 Windows CI 有 21 项删除相关测试失败。快照保存规范路径，而调用方可能使用 Windows TEMP 的短路径别名，字符串比较因此误报“文件未纳入删除快照”。已在本机短路径临时目录复现。

快照预图查找现在解析真实文件路径；缺失元数据通过最近已有父目录解析，仍要求其存在于已观察快照成员中。解析前检查链接与重解析点，不绕过指纹、哈希校验或删除事务。新增回归测试同时覆盖已有元数据、缺失元数据与未观察成员拒绝。

旧版本标签及 draft 保留。alpha.4 不视为完整验证通过；本版本仍须以同一提交的 Linux / Windows CI 与四平台 Release 结果为交付依据。制品保持 draft，未签名或公证，不迁移数据和兼容标识，也不修改真实用户 Session 来测试。

本地短路径 TEMP 环境的 Rust 库 526 项测试通过；路径回归加入安全矩阵，由每个平台在打包前执行。

发布流程见 [发布约定](../release-workflow.md)，数据保护合同见 [删除快照](../codex-delete-snapshots.md)。
