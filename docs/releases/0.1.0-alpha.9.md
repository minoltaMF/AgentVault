# AgentVault 0.1.0-alpha.9

统一工作台新增腾讯 WorkBuddy、官方 xAI Grok Build CLI 与 Pi 只读接入，支持自定义来源、可取消扫描、逐文件失败报告、会话筛选、正文搜索、命中定位与预览。六个工作台来源可同时刷新。

WorkBuddy 复用现有 Claude 消息解析，按 user_query / output_text 规则区分用户正文与系统上下文；不读取 workbuddy.db 自定义标题或图片附件。Grok 依据官方 updates 协议聚合流式片段，并复用上游 rewind 算法排除撤回分支。Pi 复用仓库已有 provider-pi 与分支图，只投影当前路径。新增来源不提供原生写入、删除、恢复或续聊。

Grok 和 Pi 当前需要完整读取单个会话后投影与分页，不宣称已实现随机访问索引；坏 JSON 或未写完尾行通过失败报告提示刷新。默认路径、来源证据与验证记录见 [统一工作台](../unified-session-workbench.md)，上游版权见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。标签仅触发 draft 制品，不正式发布。

本地验证：前端 89 项、Rust lib 545 项、安全矩阵 12/12 通过；前端/CLI 构建、格式与发布元数据检查通过。真实 Rust WebUI 临时原生夹具的三来源读取、搜索、命中预览、只读菜单及桌面/窄窗口检查通过，源文件哈希未变。CI 和制品需以对应工作流最终结果为准。
