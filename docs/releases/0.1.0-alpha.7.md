# AgentVault 0.1.0-alpha.7

统一工作台接入正文搜索与命中定位。复用 cc-sessions 基线的流式全文搜索、单活动任务管理、摘要与只读预览，在一个任务内搜索当前筛选范围的 Codex 与 Claude 会话，不限于列表当前页。

搜索必须手动启动；结果标明来源，点击命中定位消息，关闭预览回到搜索结果。查询与已结束的结果在同一应用会话内保留，来源或筛选范围变化后失效。离页和关闭搜索请求取消，迟到的启动响应也会取消。读取失败、文件消失与坏 JSON 有限量报告；最多返回 100 个会话、每会话 3 处命中，并明确提示上限。

不引入磁盘索引、向量搜索、新运行环境或新的 Agent 格式。本轮复用仓库已有代码，没有新增 casr 代码。新增 Agent 的产品身份和格式需分别核实后分批接入。

验证记录见 [统一工作台](../unified-session-workbench.md)。本地浏览器夹具验证与 Rust 测试不能替代原生桌面运行验收。按发布约定生成 draft，正式发布另行授权。
