# AgentVault 0.1.0-alpha.41

搜索命中上下文查看：在当前命中旁增加「前 3 条」「后 3 条」「返回当前命中」和「收起上下文」。可连续展开已加载范围内的相邻消息，前后始终按时间先后理解，展示顺序沿用最早/最新在前；仅看对话时也遵循相同消息筛选。非命中消息标注为上下文，不加入命中计数或上下条导航。展开、收起和返回保留当前命中消息及本条关键词位置，切换命中、关键词或会话时收起。

复用现有消息解析、关键词定位、虚拟列表与滚动稳定逻辑，邻接以筛选后的消息序列计算，不依赖源索引连续。上下文只覆盖已加载窗口，不自动扫描全会话；边界或零命中时禁用对应按钮。无后端协议、依赖、存储 schema 或原生会话写入变更。

验证：前端 183 项测试及构建通过。新增测试覆盖不连续索引、加载边界、空/消失命中、上下文与命中集合分离及导航顺序。真实 WebUI 使用 http://127.0.0.1:43279 的独立合成 Claude 夹具，验证前后各 3 条、连续展开至边界、保留第 8/8 处、收起与切换命中、倒序上下文及零命中禁用；在 1,200 条消息夹具的已加载窗口中验证第 30/30 处离屏卸载后返回。1280×720 和 390×844 布局无覆盖，控制台无相关 warning/error。Browser plugin not available，使用 CUA Playwright；一次浏览器命令超时后重新读取页面重试成功。

安全矩阵 12/12、发布流程回归 26/26、Rust 格式、版本元数据与 diff 检查通过。四平台构建及 14 件制品下载 SHA-256 校验以 CI 为准，Release 保持 draft。未逐一验收十四个来源的特殊正文格式，签名、公证与目标设备安装运行未验收。
