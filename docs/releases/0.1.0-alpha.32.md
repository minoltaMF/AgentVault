# AgentVault 0.1.0-alpha.32

用量分析新增高消耗模型与项目排行，支持按 Token 或已知费用降序排列，点击排行项查看当前日期范围内的关联会话，返回时保留排行排序及页码。

复用现有 Codex / Claude 日期筛选、去重、汇总和单价估算。模型关联会话仅计入该模型用量；项目路径缺失独立分组。Token 不重复计算推理及 1 小时缓存写入。未知费用不视为免费，部分结果及读取提示保留显示；溢出或缺失用量排在末尾。排行与关联会话均分页，每页 10 项，切换排序不读取原生文件。日期或单价变化时同步更新。

不增加原生会话写入、不修改缓存及存储 schema、不扩展 CSV 格式。本次只创建 draft；安装运行、签名及公证另行验收。

验证：`npm run test:frontend` 153/153 通过（含 7 项排行回归），`npm run build`、`npm run release:check -- --tag v0.1.0-alpha.32`、`cargo fmt --all -- --check` 和 `git diff --check` 通过。合成 Codex / Claude 会话的浏览器验收覆盖模型/项目切换、Token/费用排序、修改单价即时重排、近 7 天日期联动、关联会话及返回，以及 390×844 窄窗口；浏览器未记录 warning/error。全部使用临时夹具，没有修改真实原生会话。

宿主限制：`npm run test:safety` 因本机 Cargo registry 的 block-buffer 0.10.4 缺失源码入口而在编译前失败，本轮没有 Rust 逻辑修改；完整安全测试及桌面构建结果以同提交 CI 为准。浏览器验收不替代原生安装、签名或公证验证。
