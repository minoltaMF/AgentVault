# AgentVault 0.1.0-alpha.51

Claude 分页读取跳过所需页之前的角色分类、文本摘要和事件构造，减少连续查找深处页面时的重复工作。前缀仍逐行读取并解析 JSON，未引入游标、跨请求缓存或原生会话写入。

## 兼容与回归

- offset 仍按合法 JSON 事件计数，元数据、工具、非消息及 JSON 标量均占一个事件；空行和坏 JSON 不占偏移。返回的 index 仍为物理行号。
- 保留全坏文件的错误、混合坏行的容忍、UTF-8 读取失败、满足页大小后的停止边界、零 limit 和无界 limit 的既有语义。
- 内部事件构造明确返回一个事件，共用分类接口仍返回 Option，其他来源调用方不变。
- 新增 6 项与 alpha.50 旧循环的差分测试，比较完整返回字段及错误分类；覆盖跨 200 条边界拼页、极值、缺失文件，以及追加、截短、替换后的重新读取。

## 性能与验证

只读分页测量脚本增加 `--baseline-url`，在同一合成会话上轮换 offset、交替新旧请求，并在计时之外核对完整页面 SHA-256。测量范围为 HTTP body 完成时间，包含后端、序列化及本地传输，不等同于完整搜索或浏览器响应时间。数据及实际验收结果见 [性能记录](../preview-search-performance.md)。

- Windows VM、相同 Rust 1.90.0 x64 GNU debug 配置、30,000 条合成消息，九轮交替测量中 offset 28,000 的 HTTP body p50 从 1,111.28 降至 786.81 ms（约 29%）；首页没有显示收益，尾延迟仍有明显波动。所有新旧页面完整输出一致。
- `cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --lib`：631/631；其中 Claude 相关 21 项，新增分页回归 6 项。
- `npm run test:frontend`：226/226；`npm run test:safety`：12/12；`npm run test:release`：26/26。
- `npm run build`、`cargo fmt --all -- --check`、`npm run release:check -- --tag v0.1.0-alpha.51` 和 `git diff --check` 通过。保留既有前端大分块提示。使用上一轮恢复的隔离工具链，未改动全局环境或依赖。
- 两个实际 WebUI 后端的合成来源完成 HTTP 分页比对；单后端脚本兼容冒烟通过。无 UI 布局变更，本轮没有重复浏览器交互验收。完整桌面目标由同标签 CI 验证。
