# AgentVault 0.1.0-alpha.15

统一工作台持久索引新增 Qwen Code、GitHub Copilot CLI，共八个来源；补充 Qoder、WorkBuddy、Grok、Pi 的可重复性能基准。

- Qwen 复用现有活动分支和 UUID 分片投影，兼容同行拼接 JSON 对象；Copilot 复用现有事件分类，排除工具、注入和临时上下文。
- 支持历史索引加载、重启后命中预览、原生空刷新替换历史结果，沿用文件指纹、取消、事务失败保留和只读路径验证。
- 不新增依赖、不迁移 schema、不写入原生会话。其他六来源继续既有扫描搜索。
- 基准脚本使用临时合成会话，记录首次索引、重复搜索、重启和单文件更新，断言命中、复用数量与源文件哈希；具体结果和局限见[性能基准](../search-index-benchmark.md)。

本地验证通过：前端 100/100、Rust lib 570/570、索引专项 7/7、安全矩阵 12/12；前端与 CLI 构建、Rust 格式、版本一致性检查通过。全量测试曾暴露两组联动测试共享全局搜索管理器的竞争，现已仅在测试内增加互斥隔离，保留全部断言和应用单任务保护，完整回归重跑通过。

Rust WebUI + Edge 使用临时开源/合成夹具，在 1280×820 与 390×844 下验证 Qwen/Copilot 读取、首次索引、实际进程重启后缓存加载与复用、命中预览和返回；无浏览器应用错误，源文件 SHA-256 不变。Browser plugin not available，使用已有 Playwright 验证，没有新增浏览器依赖。

四来源大样本基准针对冻结的 alpha.14 release CLI，每来源 1,000 会话 × 100 消息；首次索引 125.66–260.47 秒，缓存三次查询中位数 1.37–4.35 秒，详见基准文档及其波动、夹具与平台限制。此数据不是新增 Qwen/Copilot 的大规模性能验收。

未验证原生安装运行、其他平台性能、真实用户语料或超长单会话。此版本仅生成 draft，不代表正式发布、签名或公证。
