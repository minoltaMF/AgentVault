# 长会话连续搜索性能（alpha.50）

本轮优化前端累计筛选，不改变分页读取协议或安全校验。原有搜索文本已使用 WeakMap；新增缓存的是当前关键词和消息筛选条件下，每个事件对象的可见性及匹配结果。连续查找与正文展示共享这些结果，避免每页对旧消息重复匹配。合并筛选遍历并复用可见事件索引；未展开上下文时直接使用匹配列表，少于两条结果时不计算间隔。

缓存仅存于当前预览内存，以不可变事件对象为键，不按源索引或路径猜测内容未变。换词、换筛选或时间线更新会失效；重读返回的新对象重新判断，关闭或换会话会更换缓存实例。没有持久缓存、schema、依赖或原生文件写入变更。累计事件数组仍需遍历，本轮不声称将总成本改为线性。

## 前端微基准

命令：`node node_modules/tsx/dist/cli.mjs scripts/benchmark-preview-search.ts --output <新的结果文件.json>`。可选 `--baseline-only`、`--rounds 5`、`--sizes 3000,10000,30000`、`--body-length 2048`。脚本仅生成内存合成事件，结果文件使用 create-if-absent，保留逐页和逐轮原始样本。

环境：Windows ARM64 / Apple Silicon、Node 24.22.1。每页 200 条、正文 2048 字符、20% 工具事件，沿用实际对话与时间线筛选函数。每种实现独立预热，再交替测量五轮；每轮使用同值但不同对象，避免互相预热文本缓存。基线保留 alpha.49 的 WeakMap 文本缓存及 map/filter 顺序。计时不含 HTTP、React 渲染和 DOM，不能解释成完整会话搜索加速比。版本比较以同批交替采样为准，前期独立基线受宿主调度影响明显更慢。

| 消息数 | 累计筛选 p50：旧 → 新 | 最后一页筛选 p50：旧 → 新 | 取消定时器派发 p50：旧 → 新 |
| --- | --- | --- | --- |
| 3,000 | 37.58 → 18.87 ms | 4.17 → 0.84 ms | 5.54 → 3.61 ms |
| 10,000 | 295.02 → 54.77 ms | 8.42 → 1.05 ms | 9.44 → 4.55 ms |
| 30,000 | 2,087.69 → 207.81 ms | 25.11 → 1.91 ms | 26.75 → 6.17 ms |

30,000 条累计筛选最大值为 2,507.90 → 589.05 ms；取消定时器派发最大值为 32.62 → 7.60 ms。五次样本的 P95 等于最大值，仅作描述，不作为稳定尾延迟或性能门禁。

取消测量在最后一页的 CPU 工作前安排零延迟定时器，观察事件循环何时能处理取消；所有样本取消后新增读取为 0。取消回调到循环退出的 p50 为 0.04 → 8.57 ms，仍受页间让出事件循环的定时器与宿主调度影响，不能宣称取消的每个阶段都更快。它也不等于浏览器点击延迟或中止后端在途 I/O。每轮摘要和取消原始样本见 [基准记录](benchmarks/preview-search-alpha50.json)。

## 后端读取基线与下一边界

可复用只读测量：`node scripts/benchmark-preview-read.mjs --base-url http://127.0.0.1:43289 --fixture <合成会话绝对路径> --output <新的结果文件.json>`。WebUI 必须已使用隔离的合成来源配置启动；脚本不启动服务、不修改会话，也不输出 API token 或正文。默认轮换 offset 0/1000/5000/10000/20000/28000，预热后各采样九次，每页 200 条。

Claude 合成 30,000 条交替 user/assistant，每条约 1 KiB，debug 后端热缓存的 HTTP body 完成 p50 分别为 37.2/97.2/304.0/554.8/1086.8/1698.3 ms，响应 JSON.parse p50 为 0.43–0.78 ms。HTTP 包括后端、序列化和传输，Windows VM 调度波动明显；该组数据不是生产 SLA，也不能与前端微基准直接相减。

Codex 和 Claude 分页仍会从头解析至指定事件偏移，Claude 还对前缀记录执行分类。下一步可先减少 Claude 被跳过记录的重复分类，验证空行、坏行、元数据与非消息记录的分页等价性。更大的游标/字节位置缓存必须独立覆盖文件追加、截短、替换和失效检测；不能把物理行号当作有效事件序号或绕过原有路径保护。

## 实际界面验收

临时 WebUI、合成 900/30,000 条会话：跨过隐藏整页后停在新命中；前后上下文及间隔展开保持命中；换词清除旧结果；切换消息模式重新计算间隔。长会话取消后范围稳定在 1–1800，重新启动再改词使旧任务失效；390×844 窄窗口再次取消后保留 1–2800。完整无命中扫描正确报告整个会话。界面正常渲染、无框架错误覆盖层，控制台未见错误。

界面使用恢复后的 CUA 浏览器控制验收，未修改真实会话。前端 226 项测试和构建通过。安全测试的环境恢复及发布状态见本版本发布说明。
