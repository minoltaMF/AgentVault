# 统一只读会话工作台

入口是侧栏「全局 → 全部会话」（`/all-sessions`）。支持设置中的 Codex、Claude、Qoder CLI、WorkBuddy、Grok Build CLI、Pi、DSH、Hermes Agent、ZCode、OpenCode、Qwen Code、Cline CLI/Desktop、GitHub Copilot CLI 与 Antigravity 十四个来源；打开页面不会自动扫描，点击来源卡片可单独读取，顶部刷新可同时读取已配置来源。

## 当前行为

- 每个来源独立显示路径、读取状态、最近成功时间和失败原因。一个来源失败不会清空另一个来源，也不会清除该来源上次成功的结果；旧结果带时间提示。
- 列表按更新时间降序，每页 50 条。支持 Provider、完整项目路径、归档状态筛选，以及标题、首条消息、ID、路径搜索。该搜索不是全文索引；同名项目不按目录 basename 合并。
- 点击标题打开现有对话预览，保持筛选和列表位置。只读模式隐藏编辑、删除、分叉和编辑历史入口；可复制 ID 与路径；只有已有续聊能力的来源显示 resume 命令，不自动启动原生 Agent。
- UI 身份复用 Provider 与实际会话路径组合，避免跨 Provider 同 ID、Claude 同 ID 多个文件发生串选。
- 筛选保存在 URL，并在当前应用会话内记住最近一次视图。切换其他页面后从侧栏返回，恢复来源结果、筛选、页码和滚动位置，不自动重新扫描；带筛选参数的显式 URL 优先于保存的筛选。
- 缓存只保留每个 Provider 当前来源的成功结果（包括空结果、部分完成报告和扫描时间），不落盘。刷新失败或取消不替换缓存；返回时显示上次扫描时间，需手动刷新获取新内容。重新加载页面、关闭应用或打开新窗口后需重新读取。
- 来源目录改变时丢弃受影响的缓存并使旧请求失效；Claude 的来源注记还依赖 Codex 目录，后者改变也会使 Claude 缓存失效。来源组合改变重置保存的列表位置，不复用已离开的来源历史。缓存不代表备份，也不证明源文件仍然存在。
- 来源读取是独立后台任务。页面显示发现文件、读取索引、读取文件等实际阶段，以及已发现、已处理和失败计数；发现与读取交替进行，不把当前发现数量当作最终总量，也不显示估算百分比。
- 「停止扫描」向后端发送取消请求，收到终态后才显示「已停止」。取消不会用未完成结果覆盖上次列表，可再次读取。离开页面会请求取消；启动响应较晚返回时仍会补发取消。断网时取消无法保证送达，重新进入并读取同一来源可接回仍在运行的任务。
- 状态查询失败显示「状态待确认」，保留任务 ID，提供重试查询和停止；不会直接当作扫描已结束或新建重复任务。
- 坏 JSON、缺失/不可读文件和不可遍历目录记录路径与原因，其他文件继续读取；结束时标为「部分完成」。失败详情最多保留 200 项，总数完整计入统计；目录失败也属于失败项。源目录或必需索引整体不可用时仍整体失败并保留旧列表。

## 实现边界

扫描任务复用现有 Codex 索引摘要、Claude 解析、归档解析和来源注记，旧 `list_sessions` 行为保留。没有迁移数据库、配置路径或修改原生会话的写入逻辑；DSH 的 Zstd 解压新增 Rust zstd 依赖。读取成功只表示本次扫描完成，不表示备份健康、完整索引或原生续聊可用。

本功能仍不包含 Registry/FTS、Doctor 诊断或后台自动刷新。任务在内存中保留，最多 14 个运行任务、16 个任务记录，仅淘汰已结束记录；同一 Provider 与来源的运行任务会被复用。运行中状态查询不复制完整会话结果，终态才返回结果。

新扫描入口逐文件先检查 JSONL 格式，再复用原解析器，可能发生两次读取；含坏行的文件整项报告失败，旧列表的宽松解析行为不变。取消在目录项、文件和行处理边界检查，不能中断操作系统正在阻塞的单次读取。JSONL 来源按文件计数，SQLite 来源按会话计数；这些计数不代表数据库行数或读取字节数；大规模耗时与内存仍需独立基准验证。

下一步性能建议：合并 JSONL 验证与摘要解析为单次流式读取，并用固定数据集测量扫描耗时、取消延迟与峰值内存。

## 正文搜索与命中定位

- 列表筛选仍只匹配标题、首条消息、ID 和路径；「搜索正文」由用户手动启动，针对筛选后的全部已读取会话，不限于当前页。
- 复用现有 content_search 单活动任务管理，在一个任务内处理上述十四个来源的显式会话集合。空集合不发现默认来源；最终文件来自对应来源列表，并在读取前检查路径边界。
- 搜索用户与助手消息，不包括全部工具输出。最多返回 100 个会话，每会话展示 3 处命中；结果达到上限时提示截断。
- 命中携带来源、消息行号和预览偏移，复用只读 PreviewDialog 定位。关闭预览返回原搜索结果，关闭搜索返回原列表页。
- 同一应用会话内保留查询和已结束结果；来源、项目、归档或列表筛选范围变化时失效，不持久化到磁盘。关闭或离页取消任务，迟到启动响应补发取消。
- 工作台搜索按来源协议检查 JSONL、压缩日志或数据库记录，失败会话不发布部分命中；文件消失、来源失败或读取失败会显示报告，最多保留 100 项详情。旧单来源搜索保留原解析行为。
- 来源发现阶段尚无最终字节总量；进入正文读取后展示已读字节与总字节。阻塞中的单次系统 IO 仍不能立即中断。

## Qoder CLI 只读来源

设置页新增 Qoder CLI 配置目录，默认遵循 `QODER_CONFIG_DIR`，否则使用 `~/.qoder`。工作台手动读取 `projects/<project>/<session>.jsonl`，复用既有可取消扫描、失败报告和搜索任务。Qoder 入口为「全局 → 全部会话」，不启用原生写入、删除、恢复、续聊或格式转换。

格式证据来自 [Qoder CLI 官方会话文档](https://docs.qoder.com/zh/cli/sessions)；回归复用 kage 的 MIT 夹具（CLI 0.1.29），来源与锁定 commit 见 THIRD_PARTY_NOTICES.md。不把 Qoder IDE、QoderWork、执行日志或子代理目录当作主会话。官方新 `state.json` 没有稳定公开 schema，本轮不依赖它推断会话正文。

## 长会话预览

预览工具栏可切换「最早在前／最新在前」，也可直接跳到最早或最新。跳到末尾和搜索命中时按目标位置读取 200 条事件窗口，保留原始事件索引用于定位。消息区与时间线复用 TanStack 虚拟列表，只挂载可视区域附近节点；展开很长的过程分组时分段显示。

此优化降低浏览器渲染与传输开销，不意味着 JSONL 底层 IO 已有随机访问索引。显式加载全部仍会占用与会话大小相关的内存；首次提问时间线读取仍需遍历来源文件。原生文件不被改写。

## 用量缓存管理与安全重建（alpha.26）

用量窗口的缓存管理区显示磁盘大小、内存条目数和估算占用，支持手动刷新状态。状态来自最近分析/重建结果及当前路径元数据；初次尚未加载的文件显示「等待校验」，不是已通过内容校验。

「安全重建缓存」取代通常需要手动移走损坏文件的流程：先将旧缓存原样备份到同目录唯一文件并读回校验，再以原子 CAS 替换为空快照，清空内存缓存并重新分析当前筛选范围。当前范围外的用量随后按需重建。模型单价、原生会话、正文搜索索引和数据库保持原状。缓存缺失时直接创建空快照；分析或取消尚未结束时拒绝重建。

链接、非普通文件、超过 64 MiB 的缓存、备份写入/校验失败和并发改动都会拒绝替换。界面保留失败提示及本次进程最近备份的位置，备份文件不会自动删除或覆盖。容量统计只计算当前缓存文件，不包含历史备份；重建成功后备份仍需用户按需保留。详情见 [alpha.26 发布说明](releases/0.1.0-alpha.26.md)。

## 用量日期筛选与按日趋势（alpha.27）

Codex / Claude 用量窗口支持全部日期、包含 UTC 今天的近 7 / 30 天及自定义首尾日期（均包含端点，单侧留空表示不限制）。日期按原生用量事件的 RFC3339 时间转换为 UTC，与设备时区、会话创建日期及文件修改时间无关。跨日累计差分不重置基线；相同响应重放保留原日期，确认的用量修订整体归入修订事件日。首条仅有累计值等既有统计歧义仍显示提示，不承诺精确账单。

筛选在已解析结果上执行，不重新读取来源；上方成功文件数仍为整个请求范围，下方汇总、会话/模型/项目明细只统计所选日期的用量。同一会话跨日可出现在多个日统计中，每日会话数不可直接相加作为唯一会话数。缺失、无效或无法表示为四位年份的时间归入「日期未知」：保留在全部日期汇总，排除于日期区间和趋势，界面提示涉及的会话数。

图表切换 Token 与费用，复用现有 EChart；Token 合计为未缓存输入、输出、缓存读取、缓存写入，不重复计算推理和 1 小时缓存子集。仅展示有用量记录的日期，缺日不是零消耗；超过 90 个日期时图表仅显示最近 90 个有记录日期，表格保留全部并每页 10 行。表格支持最新、Token 最高、已知费用最高排序；点击日期查看当天明细，点击全部日期恢复。费用采用本机当前录入单价，缺单价、解析警告或溢出不会显示为完整账单；排序仅比较已知金额。

日桶与未知日期模型合计一同持久缓存。解析版本由 1 升为 2，旧文件保留并降级到内存缓存，原生会话正常重新解析。点击「安全重建缓存」会按 alpha.26 的备份、读回验证及 CAS 保护生成新快照，再分析当前工作台范围；没有迁移数据库 schema、配置目录或缓存文件名。没有新增依赖或外部服务；沿用已登记的 Magpie 用量解析复用。

## 用量周期对比（alpha.28）

用量窗口增加「周期对比」，支持最近 7 天或 30 天与紧邻上一周期比较。沿用原生事件的 UTC 日期与已有去重后的日桶；本期含截止日，上一周期在本期开始前一天结束，两个区间等长且不重叠。本期包含尚未结束的今天，不估算全天，也不按当前时刻截短上期；两期精确日期和有记录天数始终可见。日期基准在打开对比或点击周期时确定，点击同一周期可刷新到新的 UTC 今天。

比较基于当前工作台筛选范围的全部 Codex / Claude 成功结果，与下方日期筛选独立。切换周期复用内存结果，不重新分析文件。点击查看本期/上期明细，将对应日期范围传给原有趋势及会话、模型、项目分组并滚动至日期区；该范围不会反过来截断对比数据。

Token 合计不重复计算推理、1 小时缓存写入等子集。费用统一使用本机当前录入单价，两期同步重算，不代表历史账单。两期有记录且质量完整时展示差额和百分比；前期明确记录为零、当前非零时只展示差额，不生成无限百分比。缺失模型单价时费用仅展示「已知差额」，不展示百分比；Token 对比不受缺价影响。无用量记录的周期不当作零值。当前请求未完整完成、存在失败/解析警告、缺失用量、无法归日或安全计算溢出时暂停两类差额，保留已读取的两期值与原因；全请求范围中无法归日的数据可能属于任意周期，因此保守影响整个对比。

缺日不等于零消耗，所有指标只描述当前已读取范围；没有推断未扫描来源、删除会话或历史价格。只增加前端纯汇总与界面，不改用量解析器、缓存格式/版本、数据库 schema 或原生来源。测试与交付记录见 [alpha.28 发布说明](releases/0.1.0-alpha.28.md)。

## 用量 CSV 导出（alpha.29）

用量窗口可导出当前日期范围的汇总、全部每日趋势与当前所选 7/30 天周期对比。周期比较继续独立于下方日期筛选，采用界面相同的 UTC 截止日期；每日数据不受 90 日图表上限或分页限制。导出只使用已加载用量，不重新读取原生会话。

文件为带 UTF-8 BOM 的 CSV，包含数值列与数据完整性说明。保留缺单价、无日期用量、解析警告、分析失败/取消及缓存提示；未知或无法计算的值不会伪装成零。金额为当前录入单价下的 USD 估算，不等于历史账单。不包含对话正文。文本字段转义引号、逗号、换行并防止被表格软件当作公式执行。

分析进行中禁用导出，结束或取消后可导出已获得的结果；无效日期范围须先修正。浏览器使用本机下载；桌面使用保存对话框，采用原子 create-if-absent 写入新的绝对 `.csv` 路径，拒绝已有文件及符号链接目标，单文件上限 32 MiB。取消保存不写文件；保存失败显示错误，可重新选择文件。

## 模型单价管理（alpha.30）

用量窗口集中展示当前分析范围实际缺价字段，可切换所有已配置模型、按来源或模型搜索、每页 10 个模型编辑。五类单价按 USD / 百万 Token 录入；空值表示未知，0 表示免费。跨筛选、分页保留草稿，保存全部修改前完整校验，失败保留原值与草稿。关闭窗口提示放弃未保存内容；其他窗口修改配置后拒绝当前旧快照保存，提示重新载入。此检查不是跨窗口原子事务。

JSON 使用既有 `{version:1,prices:{...}}` 格式及本地存储键；导入先验证再展示合并预览，只有应用后写入。未提供字段和模型不删除，导出仅包含已保存配置。文件及合并结果最多 1 MiB / 1000 模型；空模型名保持兼容。浏览器文件选择与下载，桌面有界读取及原子新建，不覆盖已有导出文件。配置不包含会话正文或路径，不接入在线价格。


## 单价历史与恢复（alpha.31）

批量编辑、导入和恢复前自动保留原配置，通过变更历史预览并恢复整份配置。恢复操作也会记录，可再次撤回。历史仅在本机保留最多 20 条、2 MiB；按最旧记录淘汰，不修改原生会话。写前历史失败则拒绝保存；损坏历史不会静默重置。新版窗口使用 Web Locks 串行写入，旧客户端写入不受此锁约束。


## 高消耗模型与项目排行（alpha.32）

用量窗口在当前日期范围内提供模型/项目排行，按 Token 或已知费用排序。选择条目可就地查看关联会话用量并返回，保留排序及页码。模型详情只包含该模型用量，不计入同一会话的其他模型。未知费用及部分读取明确提示，无效或缺失用量置后；日期和单价更新同步重算，不重新读取文件。

## 排行正文追查（alpha.33）

排行关联会话支持打开完整只读正文；返回按钮、Esc 和关闭按钮恢复原会话入口焦点与滚动位置。用量窗口保持挂载，保留日期、分组、排序、分页与单价草稿，不重复分析。匹配仅使用当前范围内唯一的来源与原生路径；完整正文不受排行日期或模型筛选限制。

## 正文读取异常与重试（alpha.34）

空正文、当前页为空、筛选无匹配、文件失效和读取失败分别提示。错误常驻正文上方并提供详情与从最早位置重新读取；部分内容不标成完整会话或末尾。关闭/切换后的旧请求沿用代次隔离。Codex/Claude 完全不可解析的非空文件会失败，混合损坏行仍保留原有容错；不引入写入或 schema 变化。


## 正文阅读位置记忆（alpha.35）

按来源和精确原生路径持久记录最近 100 个会话的阅读事件、排序及消息显示模式。普通打开读取目标附近的窗口，核对事件原始索引和内容变化摘要后定位；虚拟列表完成高度测量后稳定锚点，避免重复打开逐步偏移。搜索跳转优先且不覆盖原阅读位置，读取失败不覆盖；文件截短或目标改写则明确提示并回到开头。恢复提示提供「从最早位置阅读」。备份/导入预览不记录。

记录只存本机 localStorage 的位置和摘要，不存正文，不修改原生文件，不迁移后端配置或 schema。记录是事件级而非长消息内部的像素级；浏览器不同 origin 与桌面 WebView 各自保存，清理站点数据会清除记录。恢复窗口不等于取消原有时间线扫描，内容摘要也不替代安全指纹。验证见 `docs/releases/0.1.0-alpha.35.md`。


## 正文搜索命中导航（alpha.37）

正文筛选支持当前命中 / 命中消息数、上一处 / 下一处和 Enter / Shift+Enter，按显示顺序首尾循环。当前命中消息显示边框高亮，定位复用虚拟列表和原始事件索引；一条消息中的重复词语只计为一条命中。

范围默认是当前已加载事件，页面明确标注，点击「加载全部」后再扩展到完整会话；加载过程及失败不冒充完整结果。扩大范围保留仍存在的当前命中，失败后已加载部分仍可导航。关键词变化或清除时取消旧定位，空结果及单结果禁用导航按钮；外部搜索目标优先，搜索不覆盖普通阅读记录。验证见 `docs/releases/0.1.0-alpha.37.md`。


## 正文关键词高亮（alpha.38）

正文搜索复用现有字面、不区分大小写匹配规则，在 Markdown 渲染后的可见文字、代码、表格及展开的纯文本/JSON 中添加高亮。保留原文和链接属性；清除搜索立即移除装饰。导航优先对齐消息中首个高亮词，无可见高亮则回退到消息起点。仍按命中消息计数，仍搜索已加载范围；折叠内容需展开，原始属性或 Markdown 标记的匹配不一定有可见高亮。不增加后端协议、索引、依赖或原生会话写入。


## 搜索自动展开（alpha.39）

命中推理、工具/事件原始数据或嵌入历史内部文字时自动展开，并先定位内部滚动区域中的高亮词。普通展开状态在当前预览中按事件保留，搜索期间的手动收起只作用于当前词；换词或清除后恢复原状态，关闭/换会话重置。继续尊重「仅看对话消息」和已加载范围，不增加写入、扫描或持久配置。


## 单条消息多处命中（alpha.40）

消息级上条/下条之外增加本条上处/下处、位置计数和当前词强调样式。按已展开正文计数，排除折叠按钮中的重复摘要，跨行内格式的同一匹配只计一次。展开状态变化更新计数；切换消息或词重置选择；虚拟行卸载后保留计数，继续导航重新定位。继续复用嵌入历史滚动保护和已加载范围，不新增后端扫描或数据写入。

### alpha.41：搜索命中上下文查看

当前命中可按时间顺序逐批展开前后各 3 条已加载消息，遵循「仅看对话」筛选和当前展示排序。上下文单独标注，不参与命中计数；展开、收起与返回沿用当前关键词位置。切命中、关键词或会话后重置展开范围，不隐式读取完整会话。回归覆盖非连续源索引与边界；真实界面验证 8/8 处保持、零命中、倒序、窄屏及 1,200 条夹具中离屏卸载后返回 30/30 处。

### alpha.42：搜索上下文跨页加载

上下文不足 3 条时允许单次读取相邻一页原始事件，最多 200 条，不自动连读；整页被过滤时允许继续点击。单独保存尾部 EOF，支持双向追加并保留命中及关键词序号。失败可原地重试，不清空已读内容；切查询、筛选或时间线会使旧请求的定位更新失效。合成 900 条夹具验证后补 200→400→600、隐藏整页停止、倒序前补、缺失文件后重试保持 8/8 处和窄屏返回。

### alpha.43：搜索结果间隔提示

在相邻显示结果之间标示已加载且符合当前筛选的省略消息，按实际事件集合计数，不使用源索引差。支持正序、倒序和每次最多 20 条就地展开；展开内容标为非命中上下文，不改变当前命中及关键词序号，可返回命中或统一收起。切词、会话或消息筛选清除展开状态，不隐式读取未加载页。合成夹具及桌面、窄屏界面验收通过。

### alpha.44：正文搜索工具栏精简

上下文展开与收起、间隔收起及搜索范围说明移入默认关闭的“上下文与选项”浮层。消息和关键词导航、返回命中、清除搜索继续直接可用；异步读取状态和失败提示保留在外，浮层内可重试。复用 Popover 焦点和键盘行为，不改变展开消息及命中位置。桌面及窄屏使用合成会话验收，390 像素宽下正文起点上移约 98 像素。
