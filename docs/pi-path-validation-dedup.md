# Pi 单次索引读取路径校验复用

2026-10-08，alpha.19。依据 [alpha.18 专项诊断](pi-search-tail-diagnosis.md)，只合并工作台边界检查与 Pi 注册之间的重复完整路径遍历。

## 实现与边界

打开前，`validate_index_source` 执行原有 Pi 布局校验和完整 `validate_descendant`，返回私有、不可复制且只消费一次的 `ValidatedIndexSource`。取消请求提前返回。打开文件及读取初始指纹后，消费此结果，使用 `symlink_metadata` 重新逐项检查来源根、父目录和文件，拒绝 link/reparse、缺失和错误类型，再登记预览来源；不重复 canonicalize。最终指纹复核未修改。

没有跨查询的路径可信缓存，ROOTS 也不保存校验结果。冷索引、热索引和仅刷新不返回结果的查询都经过打开前检查；扫描、预览和需要重新解析正文时的原有检查不变。其他 Provider 的边界校验未修改。数据库 schema、原生文件和兼容标识未改变。

逐项检查仍不是原子路径打开；这次保留了对持续存在的链接替换的拒绝能力，不宣称消除所有 TOCTOU。最终指纹仍使用原有实现，不能单独替代路径类型和链接复查。历史 29 秒事件的根因仍未确定。

## 回归验证

Windows 本地 `cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --lib`：578/578；前端 100/100、安全矩阵 12/12、基准统计 3/3；前端构建、release CLI 构建、格式检查和版本检查通过。桌面及 Unix 目标由 CI 验证。

新增确定性测试覆盖校验后文件删除、文件变目录、父目录变文件、来源根消失；Windows 在校验后、打开前将父目录替换为 junction，打开后的复查拒绝它。Unix 用例覆盖打开后叶子及父目录 symlink 替换。热索引与 `query=None` 都拒绝错误根、Pi 布局之外和已删除文件；取消查询不登记来源。原有活动分支、正文变化拒绝、重启复用和命中偏移测试继续通过。

同时修复 Pi 测试夹具仅以时钟命名导致的并发目录碰撞，补充进程内唯一序号。初次测试暴露的夹具碰撞、Windows 打开句柄阻止目录重命名以及 mklink 不接受混合路径分隔符，均在最终测试前修正；没有跳过或放宽测试。

## 同夹具交替基准

证据：[完整采样 JSON](benchmarks/pi-path-dedup-alpha19-20261008.json)。旧版为 `0a297cc4679aa403cbcc6a5ad951f78219b30ee6` 对应 alpha.18 冻结程序，新版为本次 alpha.19。二进制 SHA-256、版本、时段、每个查询的阶段计时与资源计数保存在证据中。

使用现有 `benchmark-pi-tail.mjs`，1,000 会话 × 100 消息 × 1,024 字符；两个程序共用同一批合成源文件及派生索引，30 轮 AB/BA 交替，每次启动对三类查询预热后各测一次。共 180 正式样本、180 预热及一次建索引；所有正式与预热查询均 0 重建、1,000 复用，命中和预览偏移正确，源文件前后哈希一致。没有剔除慢样本。

Windows ARM64 虚拟机运行 x64 GNU release 程序，Rust 1.90.0、llvm-mingw 20260908；开始正式采样前编译和测试已结束。P95 使用 nearest-rank，每类每版本 30 个样本。

正式样本来源校验中位数 498.5 → 360.1 ms（约 -27.8%）；第二次完整验证 214.8 ms 替换为打开后复查 71.0 ms。首次完整边界检查 221.9 → 227.9 ms，最终指纹 22.2 → 22.8 ms；这两处未被取消。每个查询仍记录 1,000 次首次边界检查、1,000 次打开后复查和 1,000 次最终指纹检查。阶段计时嵌套，不能重复相加。

工作线程 CPU 中位数 765.6 → 625.0 ms，进程其他 I/O 操作中位数 121,883 → 85,880；该计数不是物理磁盘读取次数。配对差值中位数 -157.1 ms，76/90 组快至少 25 ms，12/90 组慢至少 25 ms，其余 2 组在 ±25 ms 内。结果支持减少固定校验开销，但不能保证每个尾部样本改善。

本轮没有采集 ETW 或系统采样器，不据此解释具体系统等待。单机结果不能替代原生 Windows、多平台或真实大型目录验收；历史 29 秒暂停未复现，不宣称已修复。后续若继续定位极端尾延迟，应保留当前安全检查并在能取得调度轨迹的环境复现。
